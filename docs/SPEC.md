# 차량 매크로 기획서 (1단계 확정본)

2021 쏘렌토 MQ4 · 기아 앱(Kia) · 스마트싱스 연동 불가 → 집에 둔 픽셀1이 기아 앱을 대신 눌러 주는 구조.

화면 시안: https://claude.ai/artifact/XPPixUw5H8Szkm2gGYuSZ6

---

## 1. 역할 나누기

| 누가 | 하는 일 |
|---|---|
| **사용자 (갤럭시 루틴·빅스비)** | 언제 실행할지 전부: 퇴근 모드, 시간대, 날씨·온도 판단, 대기 시간, 측면 버튼 연결 |
| **리모컨 앱 (내 갤럭시)** | 실행 아이콘·위젯으로 신호 보내기, 결과 알림 보여주기, 픽셀1 상태 감시 |
| **수신기 앱 (집 픽셀1)** | 신호 받으면 기아 앱 조작 → 결과 돌려보내기. 판단은 하지 않음 |

> 대기 시간·온도 조건·시간대는 앱이 판단하지 않는다. 앱은 신호만 보낸다.

```
갤럭시 루틴 / 빅스비 / 측면 버튼 / 위젯
        │  (실행 아이콘 열기)
        ▼
리모컨 앱 ──(ntfy 중계, HMAC 서명)──▶ 픽셀1 수신기 ──▶ 기아 앱 조작
        ▲                                   │
        └──────────── 결과 ─────────────────┘
```

## 2. 1단계 기능

| 기능 | 기아 앱에서 하는 일 | PIN |
|---|---|---|
| 문 열기 | 제어 탭 → '문 / 잠금 해제' | 나옴 |
| 문 잠그기 | 제어 탭 → '문 / 잠금' | 안 나옴 (확인됨) |
| 시동 켜기 (프리셋) | 시동/공조 설정에서 프리셋 적용 → '시동/공조 켜기' | 나오면 입력 |
| 시동 · 최대 난방 | 제어 탭 → '최대 난방 켜기' | 나오면 입력 |
| 시동 끄기 | 제어 탭 → 시동/공조 '끄기' | 나오면 입력 |

### 공조 프리셋 (3개 고정: 한파·난방·냉방, 값은 픽셀1 앱에서 편집)

| 프리셋(기본값) | 희망 온도 | 앞유리 성에 제거 | 미러+뒷유리 열선 | 핸들 열선 | 시트 열선/통풍 | 시동 유지 시간 |
|---|---|---|---|---|---|---|
| 한파 | High | 켬 | 켬 | 켬 | 열선 최대 | 10분 |
| 난방 | 25℃ | 끔 | 끔 | 켬 | 열선 중간 | 10분 |
| 냉방 | Low | 끔 | 끔 | 끔 | 통풍 | 10분 |

- 희망 온도: 팝업의 현재 값(Low/숫자/High)을 읽고 목표가 될 때까지 +/− 누름 → 적용
- 스위치: 현재 켜짐/꺼짐을 읽고 다를 때만 누름
- 시트 열선/통풍, 시동 유지 시간: 하위 화면에서 선택 (선택지는 화면 분석으로 확정)
- 바꾼 설정은 기아 계정에 그대로 남음 (내 폰 기아 앱에도 반영)

## 3. 실행 방법 (리모컨)

이 앱은 **루틴 자동화 전용**. 직접 누를 때는 기아 앱 위젯을 쓴다 (리모컨 위젯 없음).

**앱 동작** (앱 바로가기. 갤럭시 루틴 '앱 동작 실행', 빅스비, 앱 아이콘 길게 누르기 메뉴에서 사용. 화면 없이 신호만 보내고 닫힘)
- 차 문 열기 / 차 문 잠그기
- 차 시동 · 한파 / 난방 / 냉방 / 최대 난방
- 차 시동 끄기
- **퇴근 신호**: 진동만 주고 닫힘, 차 명령 없음. 루틴 조건 "앱이 열렸을 때"로 사용

**리모컨 앱 화면 (상태판)**: 픽셀1 상태(배터리·충전·Wi-Fi·기아 로그인·마지막 신호), 차 상태(문, 시동 남은 시간), 최근 실행 기록 20건, 테스트 실행(확인 창 후 전송)

## 4. 안전장치
- 명령은 페어링 코드 비밀키로 HMAC-SHA256 서명, 2분 지난 명령·재전송 무시
- 테스트 실행은 확인 창을 거쳐야 전송
- **문 열기 실행 아이콘은 폰 잠금 해제 상태에서만 동작** (잠긴 폰에 빅스비로 여는 것 방지)
- **시동 아이콘은 잠금 상태에서도 동작** (락커에 둔 폰에서 루틴이 실행해야 하므로)
- 같은 명령 짧은 시간 중복 실행 방지, 수신기는 한 번에 하나씩 순서대로 처리

## 5. 알림 (리모컨)
- 명령마다 **알림 하나가 단계별로 바뀜**: 전송 → 픽셀1 받음 → 차 응답 → ✅ 성공(기아 문구 그대로) / ❌ 실패(어느 단계, 이유)
- "이미 열려 있음/잠겨 있음"이면 누르지 않고 알려줌
- 경고 알림: **픽셀1 연결 끊김** (40분 이상 상태 신호 없음, 리모컨이 15분마다 확인), **기아 앱 다시 로그인 필요**

## 6. 수신기(픽셀1) 동작 순서
1. 화면 켜기 → (보안 없는) 잠금화면 넘기기 → 기아 앱 새로 실행
2. 로그인 화면이면 → 중단, '로그인 필요' 보고
3. 하단 '제어' 탭으로 이동 (홈 탭의 '열기/닫기'는 **창문** 버튼이므로 사용 금지)
4. 대상 버튼의 현재 상태 확인 → 이미 원하는 상태면 누르지 않고 보고
5. (시동 프리셋) '시동 / 공조 설정' → 값 맞추기 → 저장 → 제어 화면 복귀
6. 버튼 누르기 → '간편비밀번호' 화면이 나오면 PIN 입력 (숫자 키패드, 고정 배열)
7. '차량 제어를 요청했습니다.' 확인 → 기아 알림 **'원격제어 결과 안내'** 문구 대기 (최대 90초)
8. 결과를 리모컨으로 전송 → 홈 화면으로

상시: 15분마다 상태 신호 (ntfy.sh 무료 한도 고려)(배터리·충전·Wi-Fi·기아 로그인), 매일 08:00 로그인 점검, 재부팅 후 자동 시작

## 7. 확인된 기아 앱 화면 정보 (2026-11 기준)
- 하단 탭: 홈 / 지도 / 제어 / 스토어 / 마이카
- 제어 탭 버튼: 시동/공조 켜기, 최대 난방 켜기, 문 [잠금 해제 | 잠금], 창문 열기, 창문 닫기, 비상등 켜기, 비상등/경적 켜기
- 문 버튼은 상태에 따라 문구가 바뀜 (잠겨 있으면 '잠금 해제', 열려 있으면 초록색 '잠금')
- PIN: '간편비밀번호 · 숫자 4자리를 눌러 주세요.', 1~9·0 고정 배열
- 성공 알림 예: "원격제어 결과 안내 — 문이 열렸습니다. 약 30초 후 자동으로 잠깁니다."
- 시동/공조 설정: 공조 모드, 시동 유지 시간, 희망 온도(+/− 버튼·슬라이더·적용), 앞유리 성에 제거, 사이드 미러+뒷유리 열선, 핸들 열선, 시트 열선/통풍

## 8. 만들면서 실제 기기로 확인할 것
- [ ] 기아 앱 버튼·스위치가 접근성으로 읽히는지 (안 읽히면 좌표 터치로 대체)
- [ ] PIN 키패드가 매번 같은 배열인지
- [ ] 갤럭시 루틴이 **폰이 잠긴 상태에서** '앱 열기'로 실행 아이콘을 여는지 (퇴근 시동의 핵심)
- [ ] 측면 버튼 두 번 누르기가 잠금 상태에서 앱을 바로 여는지
- [ ] 시트 열선/통풍·시동 유지 시간 하위 화면의 선택지
- [ ] 시동 중일 때 시동/공조 버튼 문구 ('끄기'로 바뀌는지)

## 9. 픽셀1 준비
- 화면 잠금 '없음', 충전기 상시 연결, Wi-Fi 유지
- 기아 앱 로그인 유지, 접근성 권한 켜기, 배터리 최적화 제외

## 10. 2단계 후보 (1단계 써 본 뒤 결정)
- 창문 열기/닫기, 비상등, 비상등+경적
- 차량 정보 (주행가능거리, 누적, 문 상태, 위치)
- 문 잠금 깜빡 방지 (차 블루투스 끊김 → 열려 있으면 잠그기)
- 밤 점검 (문 상태·주유 알림), 주차 위치 기억
- 가족 공유, 실행 기록 화면, 작은 2×1 위젯
