# 차량 매크로 (Car Macro)

스마트싱스 연동이 안 되는 차(예: 2021 MQ4 쏘렌토)를 위해,
**내 폰(리모컨) → 집에 있는 남는 폰(수신기, 예: 픽셀1) → 기아 앱 버튼 자동 터치 → 결과 알림**
을 해 주는 개인용 앱입니다.

```
[내 폰: 위젯 "열기"] ──(ntfy.sh, HMAC 서명)──▶ [픽셀1: 수신 서비스]
                                                   │ 접근성 서비스가 기아 앱 실행
                                                   │ "문 열림" 버튼 터치 → 성공 문구 확인
[내 폰: ✅ 문 열기 성공 알림] ◀──(결과 메시지)──────┘
```

## APK 받기
GitHub → **Actions** → 최신 "Build APK" 실행 → 하단 **Artifacts** 의 `CarMacro-apk` 다운로드 → 압축 풀어서 두 폰에 설치.
(같은 APK 하나를 두 폰에 깔고, 앱 안에서 역할을 고릅니다.)

## 설정 순서
### 1) 수신기 (픽셀1)
1. 앱 실행 → 역할: **수신기**
2. **페어링 코드 → 새로 만들기 → 복사** (카톡 나와의 채팅 등으로 내 폰에 보내기)
3. **기아 앱 선택** → 기아 앱 고르기
4. **접근성 설정** → '차량 매크로' 켜기
5. **배터리 최적화 제외** 허용
6. **수신 시작**
7. 픽셀1 설정:
   - 화면 잠금: **없음** (또는 스와이프. PIN/패턴이면 자동으로 못 풉니다)
   - 충전기에 계속 꽂아두기, Wi-Fi 연결 유지
   - (권장) 개발자 옵션 → '충전 중 화면 켜짐 유지'
   - 기아 앱에 로그인해두고, 원격제어 비밀번호(PIN) 입력이 필요하면 스크립트에 `pin 1234` 추가

### 2) 스크립트 맞추기 (중요)
기아 앱 버전마다 버튼 문구가 다르므로 기본 스크립트는 추측값입니다.
1. **5초 후 분석** 누르고 → 기아 앱의 문 열기 버튼이 보이는 화면으로 이동
2. 알림이 오면 앱으로 돌아와 버튼 목록 확인 (★ = 누를 수 있는 것, `[x,y]` = 좌표)
3. 스크립트의 `click` 문구를 실제 문구로 고침. 문구가 없으면 `click id:...` 또는 `tap x y`
4. 기아 앱에서 직접 한 번 문을 열고 다시 분석하면 성공 알림/토스트 문구가 아래쪽에 나옵니다 → `expect` 에 넣기
5. **열기 테스트** 로 확인

### 3) 리모컨 (내 폰)
1. 앱 실행 → 역할: **리모컨**
2. 복사해 온 페어링 코드 붙여넣기 → 저장
3. 홈 화면에 **차량 매크로 위젯** 추가
4. 위젯의 🔓 열기 → "전송됨 → 수신기가 받음 → ✅ 성공" 알림

## 보안
- 명령은 페어링 코드의 비밀키로 HMAC-SHA256 서명되며, 2분이 지난 명령과 같은 명령의 재전송은 무시됩니다.
- ntfy.sh 토픽 이름도 랜덤이지만 공개 서버이므로, 원하면 자체 ntfy 서버 주소를 넣을 수 있습니다.
- 페어링 코드는 차 키나 마찬가지이니 공유하지 마세요. 유출 시 새로 만들어 두 폰에 다시 넣으면 됩니다.
