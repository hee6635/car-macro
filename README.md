# 차량 매크로 (Car Macro)

스마트싱스 연동이 안 되는 2021 쏘렌토 MQ4를 위해, **내 갤럭시(리모컨) → 집 픽셀1(수신기) → 기아 앱 자동 조작 → 결과 알림**을 해 주는 개인용 앱.
기획: [docs/SPEC.md](docs/SPEC.md)

## APK 받기
GitHub → **Actions** → 최신 "Build APK" → 하단 **CarMacro-apk** 다운로드 → 압축 풀어 두 폰에 설치 (같은 APK, 앱에서 역할 선택).

## 픽셀1 (수신기) 설정
1. 앱 → 맨 아래 설정에서 역할 **수신기** → 페어링 코드 **새로 만들기 → 복사** (내 폰으로 보내기)
2. **앱 고르기** → 기아 앱 / **PIN 저장** (기아 간편비밀번호 4자리)
3. **접근성 설정** → '차량 매크로' 켜기 / **배터리 최적화 제외**
4. **수신 시작** → **로그인 점검**으로 기아 앱 조작 확인
5. 시동 프리셋 값 확인 (시트·유지 시간 문구는 기아 앱 화면 그대로)
6. 픽셀1: 화면 잠금 **없음**, 충전기 상시 연결, Wi-Fi 유지, 기아 앱 로그인 유지

## 내 폰 (리모컨) 설정
1. 역할 **리모컨** → 페어링 코드 붙여넣기 → 저장
2. 홈 화면에 **차량 매크로 위젯** 추가 (문 열기·시동은 두 번 눌러 실행)
3. 앱 목록에 생기는 실행 아이콘을 갤럭시 루틴 '앱 열기' / 빅스비 빠른 명령어에 연결
   - 차 문 열기 (폰 잠금 해제 필요), 차 문 잠금, 차 시동 · 한파/난방/냉방/최대 난방, 차 시동 끄기
   - **퇴근 신호**: 진동만, 차 명령 없음 → 루틴 조건 "앱이 열렸을 때"로 사용

## 문제가 생기면
- 기아 앱 업데이트 후 버튼을 못 찾으면: 픽셀1 앱 **5초 후 분석** → 결과 복사해서 공유
- 픽셀1 연결 끊김 알림: 픽셀1 전원/Wi-Fi 확인
